# Papua regency/city GeoJSON source

- Source authority: Badan Informasi Geospasial (BIG)
- Layer: `Wilayah Administrasi Kabupaten/Kota`
- Edition described by the service: September 2023
- Service: `https://geoservices.big.go.id/rbi/rest/services/Hosted/Wilayah_Administrasi_Kabupaten__Kota/FeatureServer/0`
- Query filter: `wadmpr = 'Papua'`
- Included features: Biak Numfor, Jayapura, Keerom, Kepulauan Yapen, Kota Jayapura, Mamberamo Raya, Sarmi, Supiori, and Waropen
- Local rendering copy: `papua-regencies.json`
- Geometry was requested in WGS84 GeoJSON with `geometryPrecision=4` and `maxAllowableOffset=0.02` for dashboard performance.

This layer is for internal monitoring visualization. It is not a legal boundary determination and does not replace authoritative boundary documents.
