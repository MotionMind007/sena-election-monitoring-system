# Papua provinces GeoJSON source

- Source authority: Badan Informasi Geospasial (BIG)
- Layer: `Area Batas Wilayah Administrasi Provinsi` (layer 12)
- Service: `https://geoservices.big.go.id/rbi/rest/services/BATASWILAYAH/BATAS_WILAYAH/MapServer/12`
- Query filter: `wadmpr LIKE 'Papua%'`
- Included provinces: Papua, Papua Barat, Papua Barat Daya, Papua Tengah, Papua Pegunungan, and Papua Selatan
- Retrieved: 30 October 2026
- Local rendering copy: `papua-provinces.json`
- Processing: features were dissolved by `wadmpr`, simplified with shape preservation, and exported as WGS84 GeoJSON with coordinate precision `0.0001`.

This layer provides visual context for internal monitoring. It is not a legal boundary determination and does not replace authoritative boundary documents.
